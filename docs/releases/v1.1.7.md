# xer 1.1.7

- Replaced `xer run` with `xer refresh`, which rebuilds and relaunches the app currently running in xer without bringing the xer window forward.
- Printed `Refreshing app…` / `Refreshed app.` in the terminal for `xer refresh`, and required xer to already be running.
- Moved terminal-command install and help out of the Run bar and project rail into Help › Terminal Commands…, with install and remove also available from the xer menu.
- Added a File menu to import a folder of projects (`⌘O`) or add a single `.xcodeproj` / `.xcworkspace` (`⇧⌘O`) without replacing other imported projects.
- Grouped the same import actions under the sidebar + control and the empty workspace.
